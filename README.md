# Fiesta - דאשבורד ניהול ספקים

מערכת לניהול ודיווח סגירות ספקים בזמן אמת.
המערכת מאפשרת לעבור על רשימת ספקים, לתעד שיחות, להעלות חוזים, לדווח לוואטסאפ ולשלוח ספקים חתומים לאתר Fiesta.

## טכנולוגיות
- **Next.js 14** (App Router)
- **MongoDB Atlas** (שמירת סטטוסים, הערות ויומן פעילות)
- **Framer Motion** (אנימציות)
- **Lucide React** (אייקונים)

## סוכנים ותפקידים
| סוכן | תחום |
|------|------|
| ינון | צלמים, וידאו, סושיאל |
| מורן | איפור, שיער, שמלות כלה, חליפות חתן |
| נתנאל | מבט מנהל — כל הספקים + סטטיסטיקות |
| מאגר כללי | גישה לכל הספקים |

## מעקב ביצועים
- **יעד יומי** — נספר לפי שיחות ב-24 שעות אחרונות (ינון: 50, מורן: 7)
- **יעד שבועי** — נספר לפי 7 ימים אחרונים (ינון: 250, מורן: 35)
- **מבט מנהל (נתנאל)** — סטטיסטיקות היום / השבוע / מצטבר לכל סוכן
- **יומן פעילות** — כל שינוי סטטוס, תזכורת והערה נשמר ב-`activityLog` ב-MongoDB

## רשימות ספקים (טאבים)
- לא נגעו בכלל · לחזור אליהם · לא ענו · עדיין לא חתם · טופלו
- כל טאב מציג מונה `(N)` בזמן אמת

## הרצה מקומית
1. העתק `.env.example` ל-`.env.local` והגדר `MONGODB_URI`
2. התקנת תלויות:
   ```bash
   npm install
   ```
3. הרצת שרת פיתוח:
   ```bash
   npm run dev
   ```

## מבנה הפרויקט
- `app/` — דפי האתר וה-API
- `app/api/states/` — CRUD לסטטוסי ספקים ב-MongoDB
- `lib/agentActivity.js` — חישוב יעדים יומיים/שבועיים וסטטיסטיקות מנהל
- `lib/agentSession.js` — שמירת סשן סוכן ב-localStorage
- `scraping/` — סקריפטים לאיסוף ועיבוד נתוני ספקים
