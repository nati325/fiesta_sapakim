# Fiesta - דאשבורד ניהול ספקים

מערכת לניהול ודיווח סגירות ספקים בזמן אמת. 
המערכת מאפשרת לעבור על רשימת ספקים, לתעד סגירות, להעלות חוזים ולדווח ישירות לוואטצאפ.

## טכנולוגיות
- **Next.js 14** (App Router)
- **Framer Motion** (אנימציות)
- **Lucide React** (אייקונים)
- **CSV Data Source** (ניהול נתונים מקומי)

## הרצה מקומית
1. התקנת תלויות:
   ```bash
   npm install
   ```
2. הרצת שרת פיתוח:
   ```bash
   npm run dev
   ```

## מבנה הפרויקט
- `app/` - דפי האתר וה-API.
- `engaged_suppliers_enriched.csv` - בסיס הנתונים של הספקים המאומתים.
- `globals.css` - מערכת העיצוב (Midnight Navy & Silver).
